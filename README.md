# pomodoro-cycle-study9
ポモドーロタイマーとストップウォッチを持つ、万能型勉強用タイマー。レベルを上げ、モチベーションを保ち続けよう！

## ヒトデクイズ動画フロー (quiz.html)
`quiz.html` を開くと、動画を再生しながら画面上にクイズが表示されます。
「ヒトデの足は5本である」という問題に対し、A（○）またはB（❌）をタッチで選択すると、
正解（A）なら正解用の動画、不正解（B）なら不正解用の動画が再生されます。
動画は `assets/videos/` 以下に配置されています（quiz.mp4 / correct.mp4 / incorrect.mp4）。
